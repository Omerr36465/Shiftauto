# Shift Auto Booker - Android Application

تطبيق أندرويد متكامل لمساعدة سائقي التوصيل في مراقبة وحجز الورديات المتاحة تلقائيًا.

## المميزات الرئيسية
- **تسجيل الدخول**: تخزين الجلسة محليًا باستخدام Room.
- **اختيار الوردية**: تحديد اليوم، الوقت، والمنطقة المستهدفة.
- **التحكم في البوت**: بدء وإيقاف المراقبة مع دعم "وضع التربو".
- **المراقبة في الخلفية**: استمرار العمل حتى عند تصغير التطبيق باستخدام Foreground Service.
- **نظام الإشعارات**: تنبيهات فورية عند توفر وردية أو نجاح الحجز.
- **تحليلات ذكية**: تتبع أنماط توفر الورديات لتحديد أوقات الذروة.
- **واجهة مستخدم محسنة**: تصميم Material Design مخصص لسائقي التوصيل (أزرار كبيرة، تباين عالٍ).

## البنية التقنية (Clean Architecture)
- **Data Layer**: المستودعات (Repositories) والنماذج وقواعد البيانات المحلية.
- **Domain Layer**: حالات الاستخدام (Use Cases) وواجهات المستودعات.
- **Presentation Layer**: ViewModels و Fragments و ViewBinding.

## متطلبات التشغيل
- Android Studio Hedgehog (2023.1.1) أو أحدث.
- JDK 17.
- Android SDK 21+.

## تعليمات بناء APK (Generate APK Build Instructions)
لبناء ملف APK جاهز للتثبيت، اتبع الخطوات التالية في Android Studio:

1. **فتح المشروع**: افتح مجلد `ShiftAutoBooker` في Android Studio.
2. **مزامنة Gradle**: انتظر حتى تنتهي عملية "Gradle Sync".
3. **بناء APK**:
   - اذهب إلى القائمة العلوية: `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`.
   - سيبدأ Android Studio في تجميع المشروع.
4. **تحديد موقع الملف**:
   - بعد الانتهاء، سيظهر إشعار في الزاوية السفلية اليمنى. اضغط على `locate`.
   - ستجد ملف APK في المسار: `app/build/outputs/apk/debug/app-debug.apk`.
5. **لإصدار نسخة Release**:
   - اذهب إلى `Build` > `Generate Signed Bundle / APK...`.
   - اختر `APK` ثم اتبع خطوات إنشاء مفتاح التوقيع (KeyStore).

## تحسينات واجهة المستخدم لسائقي التوصيل (UI Optimization)
تم تحسين الواجهة لتناسب ظروف عمل السائقين:
- **أزرار كبيرة**: لتسهيل الضغط أثناء التنقل أو ارتداء القفازات.
- **تباين عالٍ**: لضمان الرؤية الواضحة تحت أشعة الشمس.
- **تقليل النقرات**: الوصول للميزات الأساسية بأقل عدد من الخطوات.
- **مؤشرات حالة واضحة**: ألوان (أخضر/أحمر) لتمثيل حالة البوت بشكل فوري.

## التحليلات (Analytics)
يحتوي التطبيق على `ShiftAnalyticsManager` الذي يقوم بـ:
- تسجيل كل وردية تصبح متاحة.
- تحليل أوقات الذروة التي تتوفر فيها الورديات عادةً.
- مساعدة السائق في معرفة أفضل الأوقات لتشغيل البوت.
